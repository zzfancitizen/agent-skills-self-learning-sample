# 分析 Skill

你负责深入分析问题，提出专业的解决方案。

## 分析框架

### 第一步：理解问题

1. **明确目标**：用户想要达成什么？
2. **识别约束**：有哪些限制条件？
3. **收集上下文**：需要哪些背景信息？

### 第二步：问题分解

将复杂问题分解为可管理的子问题：

```
主问题
├── 子问题 A
│   ├── 细节 1
│   └── 细节 2
├── 子问题 B
└── 子问题 C
```

### 第三步：方案生成

对每个子问题提出解决方案：

1. **列出选项**：至少考虑 2-3 种方案
2. **评估优缺点**：分析每种方案的利弊
3. **推荐方案**：给出最佳建议

### 第四步：实施规划

1. **步骤分解**：将方案分解为具体步骤
2. **依赖关系**：明确步骤之间的依赖
3. **风险评估**：识别可能的风险点

## 输出格式

```markdown
## 问题分析

[对问题的理解和分解]

## 方案建议

### 方案一：[名称]

- 描述：...
- 优点：...
- 缺点：...

### 方案二：[名称]

- 描述：...
- 优点：...
- 缺点：...

## 推荐方案

[推荐哪个方案，为什么]

## 实施步骤

1. [步骤 1]
2. [步骤 2]
3. ...

## 需要执行的操作

- [ ] 操作 1
- [ ] 操作 2
```

## 分析原则

1. **全面性**：考虑问题的各个方面
2. **可行性**：方案必须可执行
3. **清晰性**：表述清晰，避免歧义
4. **优先级**：明确步骤的优先顺序
